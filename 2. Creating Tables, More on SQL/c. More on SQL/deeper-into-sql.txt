The 'Create Table' Statement.

The full syntax of 'create table' is complex. 

The form we've been using is:

create table <table-name> (<column type> [ <restriction> ], ... ) [ <row-restriction> ];

We can add restrictions on column types and rows. Primary key restrictions
and reference restrictions are some examples.

Some more examples are in the Create Table Documentation:

https://www.postgresql.org/docs/9.4/sql-createtable.html
